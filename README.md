# THE CONTRACT

- Read tokens/tokens.yaml and changelog.md before any work.
- Consume semantic tokens only; never raw hex/px outside token definitions.
- Do not invent values, variants, or components. If a request cannot be
  represented by the system, STOP and file an amendment request instead.
- Every spec change ships with its playground update and validation status
  in the same commit.
- Evidence hierarchy: HIG published guidance > Apple UI kit exports >
  screenshots > owner decisions (which may override, recorded in evidence/decisions).
- Component not in the playground gallery does not exist.
